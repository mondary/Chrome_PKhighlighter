# PK Highlighter 🖍️

![Bannière PK Highlighter](store/assets/banner-1544x500.png)

[🇫🇷 FR](README.md) · [🇬🇧 EN](README_en.md)

✨ Une extension Chrome qui surligne vos mots-clés et barre les phrases exclues, avec sept styles visuels. Made by PK-Labs.

Version : **2026.09.2**

![Surlignage réel sur un article](store/screenshots/05-reading-after.png)

## ✅ Fonctionnalités
- **Surlignage automatique** : mise en évidence immédiate des mots-clés, avec une couleur stable par mot.
- **Exclusion intelligente** : les phrases exclues sont barrées en rouge pour éviter les faux positifs.
- **Sept styles visuels** : Sticker, Candy, Offset, Bold, Origami, Pastel et Synthwave.
- **Activation par site** : le bouton **HL** ouvre le panneau, « Ajouter ce site » active le surlignage.
- **Persistance locale** : réglages enregistrés par site via le stockage local, rien ne quitte votre navigateur.

## 🧠 Utilisation
1. Cliquez sur le bouton **HL** en bas de la page pour ouvrir le panneau.
2. Activez le site courant (« + Ajouter ce site »).
3. Renseignez vos listes :
   - **Highlight** : mots/phrases à surligner (séparés par des virgules).
   - **Exclude** : mots/phrases à barrer (séparés par des virgules).
   - **Style** : choisissez le rendu visuel parmi les sept aperçus.
4. Cliquez sur **Save**. Le panneau est déplaçable, vos réglages restent enregistrés par site.

## ⚙️ Réglages
- Les exclusions sont appliquées avant le surlignage.
- Le script ignore les champs de saisie et son propre panneau d'interface.
- Le panneau contient un lien discret de soutien vers [Ko-fi](https://ko-fi.com/pouark).

## 🧪 Installation
- **Chrome Web Store** (recommandé) : [PK Highlighter](https://chromewebstore.google.com/detail/pk-highlighter/nnmkffkeilpnimdbiifhphpnflilhmno)
